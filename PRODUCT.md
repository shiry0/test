## Platform

web

## Stack

React, Three.js, React Three Fiber, and MapLibre as requested. Vite supplies the local npm development server.

## Users

The creator wants a test website to evaluate visual approaches for a NASA Space Apps project.

## Product Purpose

Provide a working local demonstration combining a rocket descent intro, MapLibre 3D terrain, a simple Three.js globe, a React Three Fiber demo, and Earth/Moon/Mars exploration.

The user now wants Mars descent to open a 2D exploration game: roam as a character, discover rocks, ancient lakebeds, and mountains, and encounter randomly spawning fictional creatures. The full game design remains open. The initial implementation uses research rewards and scanner upgrades as a provisional progression loop.

## Capabilities and Constraints

Must install and run locally. This is a demonstration, with simulated mission activity clearly identified. No existing website or source files were supplied. The final Space Apps challenge and integration target are undecided.

## Brand Commitments

The user confirmed a cinematic space journey for this test website.
